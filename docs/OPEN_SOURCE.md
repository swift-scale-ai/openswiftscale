## Community guarantees

Community Edition does not impose product-level limits on requests, tokens, providers, API users, keys, endpoint pools, or local deployments. The public repository includes:

- OpenAI-compatible inference APIs.
- Direct provider and local compatible endpoints.
- Managed API users and revocable Gateway API keys.
- Priority, weighted traffic, automatic failover, and the routing wizard.
- Static virtual model aliases.
- Local usage metadata, estimated cost, latency, and health information.
- Embedded multilingual management console.
- SQLite persistence, Docker deployment, CI, release binaries, container images, SBOMs, and provenance.

Enterprise and Cloud offerings add organization-wide governance, coordination, managed operations, and commercial support. They do not turn Community Edition into a time-limited trial. See [Community and Enterprise](ENTERPRISE.md).
