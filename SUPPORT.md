# Support

Use GitHub Issues for reproducible Community Edition bugs, documentation problems, provider compatibility reports, and focused feature proposals. Search existing issues first and include the OpenSwiftScale version, deployment method, operating system, relevant sanitized logs, and reproduction steps.

Do not post provider keys, Gateway API keys, administrator credentials, prompts, responses, customer data, database files, or master keys.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md), not through a public issue.

Community support is best effort. Enterprise support, lifecycle commitments, private deployment assistance, and SLAs are available separately from SwiftScale.
